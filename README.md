#  Groq AI Chatbot

## 📌 Project Overview

Groq AI Chatbot is an interactive AI-powered chatbot built using Python and Streamlit. It uses the Groq API to generate fast, intelligent, and helpful responses to user questions.

The chatbot acts as a personal AI assistant that helps users with coding, learning, research, general knowledge, and productivity.

## 🎯 Objectives

- Explore AI tools and Large Language Models (LLMs).
- Learn how AI can assist with coding, research, and productivity.
- Build an AI-powered application using Python.
- Understand API integration with AI models.
- Develop an interactive chatbot interface.

## ✨ Features

- 💬 Interactive chatbot interface
- ⚡ AI-powered responses using Groq API
- 🧠 Intelligent question answering
- 💻 Coding assistance
- 📚 Learning and research support
- 🗂️ Conversation history during the session
- 🗑️ Clear Chat option to reset conversations
- 🎨 User-friendly interface built with Streamlit

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- OpenAI-compatible chat completions API
- python-dotenv

## 🤖 AI Model

**Model:** `openai/gpt-oss-120b`

The chatbot uses a Groq-hosted model to generate responses based on user prompts and conversation history.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Groq-AI-Chatbot.git
```

### 2. Navigate to the Project Folder

```bash
cd Groq-AI-Chatbot
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Your API Key

Create a `.env` file in the project folder and add your Groq API key:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Get your API key from the Groq Console.

**Never share or upload your actual API key to GitHub.**

### 5. Run the Application

```bash
streamlit run app.py
```

The chatbot will open in your browser.
